# App screenshots

No in-app screenshots are included yet. Add captures only after reviewing the real app in a development build on a physical device or emulator.

## File convention

Save original PNG captures in this directory with a screen and platform name, for example:

- alarms-android.png
- destination-picker-android.png
- routes-android.png
- alarm-active-ios.png

Keep captures at their original device resolution. In the README, display them at a consistent width so the screens remain legible on GitHub.

## Capture checklist

- Capture the running application; do not use generated mockups or reconstructed UI.
- Use test destinations and remove home, work, or other personal location details.
- Check that the build shown matches the source being documented.
- Include the device and OS version when the screenshot is used as acceptance evidence.
- Avoid screenshots with provider keys, personal notifications, account details, or unrelated device data.

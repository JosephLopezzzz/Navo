What the actions do

  • Close: acknowledging this alert leaves later distance, arrival, and possible-missed alerts enabled.
  • Destination area: “I’m here” explicitly completes only this destination alarm and prevents a later false missed-stop warning.
  • Possibly passed: open the saved destination, with a point summary if map imagery is unavailable.
  • Mute this alert: silence and dismiss only the current event. It never disables later alerts or another alarm.
  • End tracking…: confirm before ending this destination alarm. Other alarms and an active route continue.
